---
title: rv configure repository
description: Configure the repositories section of the config file
---

Used to add, update, or remove [repositories](../../../config/required-fields/repositories) from the configuration file, while maintaining the file's formatting and comments.

This command has 5 subcommands for fine tuned repository configuration:

* [`add`](./add) - Add a new repository
* [`replace`](./replace) - Replace an existing repository entry
* [`update`](./update) - Update an existing repository's fields
* [`remove`](./remove) - Remove an existing repository
* [`clear`](./clear) - Clear all repositories
