---

A few other commands which can be used to control your project:

* [`rv fmt`](./fmt) - Format the configuration file to ensure consistent styling, while maintaining spacing and comments
* [`rv activate`](./activation#rv-activate) - Activate a previously initialized rv project
* [`rv deactivate`](./activation#rv-deactivate) - Deactivate an rv project
* [`rv run`](./run) - Run an Rscript command with the project library configured, syncing first by default
* [`rv export renv`](./export_renv) - Export the project's lock file to `renv.lock` format
